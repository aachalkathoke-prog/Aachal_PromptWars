# Perspective AI 🧠⚡

**Multi-Perspective Decision & Debate Intelligence Platform**

Perspective AI is an advanced multi-agent decision intelligence platform that analyzes complex dilemmas, executive decisions, and societal questions across divergent philosophical, technical, and strategic cognitive archetypes.

---

## 🚀 Key Features

1. **🌐 Multi-Persona Cognitive Lens Grid**
   - **Dr. Aris Thorne** (*Techno-Optimist / Accelerationist*): Maximizes innovation velocity and compute leverage.
   - **Elena Rostova, J.D.** (*Ethicist & Safety Auditor*): Mandates precautionary guardrails, alignment invariance, and liability accountability.
   - **Marcus Vance** (*Venture Strategist*): Focuses on capital efficiency, unit economics, and competitive moats.
   - **Maya Lin, Ph.D.** (*Labor Sociologist & Humanist*): Safeguards human agency, equity, and civic dignity.
   - **Julian Kross** (*Chief Red-Teamer & Systemic Skeptic*): Adversarial stress-testing of cascading failure modes.
   - **Dr. Soren Patel** (*First-Principles Philosopher*): Ontological inquiry into underlying axioms and social contracts.

2. **⚔️ Live Synthetic Debate Arena**
   - Multi-round structured discourse (*Opening Thesis*, *Cross-Examination*, *Rebuttals*, *Concession & Synthesis*).
   - **Live User Challenge Injection**: Directly interrogate or challenge any AI persona live during the debate.
   - Optional Text-to-Speech voice synthesis simulation.

3. **📊 Consensus & Ideological Tension Map**
   - **2D Polar Tension Radar**: Dynamic SVG spatial field plotting all perspectives across Innovation vs Precaution (X-axis) and Near-term ROI vs Long-term Humanity (Y-axis).
   - **Unanimous Common Ground**: Shared agreements where all disparate perspectives converge.
   - **Cognitive Bias Detector**: Identifies hidden biases (Status Quo bias, Optimism bias, Sunk Cost fallacy).

4. **🎯 Strategic Decision Synthesis & Phased Roadmap**
   - Interactive weighted sliders for organizational priorities (*Innovation Velocity*, *Safety Rigor*, *Capital Efficiency*, *Human Dignity*).
   - Synthesized Action Frameworks with interactive checklist tasks.
   - Phased execution Gantt-style timeline with concrete risk mitigation triggers.

5. **🧬 Persona Studio & Custom Dilemma Generator**
   - Design custom synthetic personas with fine-tuned cognitive traits.
   - Analyze ANY custom dilemma with automatic multi-perspective simulation and consensus calculations.
   - Export executive briefings to Markdown, PDF, or clipboard.

---

## 🛠️ Getting Started Locally

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to interact with Perspective AI.
